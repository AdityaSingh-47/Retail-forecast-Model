Wilcoxon signed-rank test Paper §III-I, α = 0.05

Tests whether two models' paired absolute errors differ. A non-significant result means the models are statistically tied.

These experiments go beyond the paper's headline table. They test why the models behave as they do: which features matter, what leakage would do, where the error concentrates, and how uncertain each forecast is.
